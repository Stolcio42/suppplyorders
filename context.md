# Контекст проекта "Заявки поставщикам"

## Цель
Локальное веб-приложение → облачное (Firebase) для совместного формирования заявок.
Сотрудник авторизуется → выбирает поставщика → добавляет товары в корзину → отправляет заказ руководителю или формирует текстовые сообщения.
Руководитель видит общую статистику и историю всех заказов.

## Текущий статус (локальная версия, работает на GitHub Pages)
- Полнофункциональное однопользовательское приложение.
- Каталог товаров (data.json) с тремя поставщиками.
- Корзина с управлением количеством, ограничением 20 шт., итоговой суммой.
- Генерация текстовых сообщений по поставщикам с копированием.
- Сохранение корзины и истории заказов в localStorage.
- Страница истории с повтором, удалением отдельных заказов и очисткой всей истории.
- Поиск по всем поставщикам / внутри выбранного (подсветка совпадений).
- Индикатор загрузки при старте.
- Кнопка очистки корзины.
- Авторизация с выбором имени сотрудника (общий пароль).
- Тёмная тема (сохраняется в localStorage).
- Резервное копирование истории (скачивание JSON).
- Сжатие изображений (скрипт compress.js).
- Service Worker для кэширования и уведомлений об обновлении (баннер "Доступна новая версия").
- Страница статистики (stats.html): фильтр по периоду, сводка, топ-5 по частоте и сумме, детализация по товарам, экспорт в CSV.

## Планируемое развитие (переход на Firebase)
- Замена localStorage на Firestore для корзины и истории заказов.
- Firebase Auth для индивидуальных аккаунтов сотрудников.
- Разграничение ролей: сотрудник видит только свои заказы; руководитель видит всё + общую статистику.
- Разделение понятий "черновик корзины" и "подтверждённый заказ": только подтверждённые заказы попадают в историю и статистику.
- Обновление всех страниц (index, history, stats) для работы с Firestore.
- Правила безопасности Firestore для защиты данных.

## Структура файлов (текущая)
- index.html (главный интерфейс)
- history.html (история заказов)
- stats.html (статистика)
- style.css (все стили, включая тёмную тему)
- script.js (логика, localStorage)
- data.json (каталог)
- sw.js (service worker)
- compress.js (сжатие изображений, локальный скрипт)
- images/ (фото товаров)
- project-context.md

## Ключевые технические моменты
- Все цвета вынесены в CSS-переменные (:root и .dark-theme).
- Service Worker кэширует основные ресурсы, при обновлении меняется CACHE_NAME.
- Поиск реализован через filterAndRenderProducts, buildProductCard, highlightText (подсветка mark).
- Статистика использует sessionStorage для флага "from_history", localStorage для orderHistory.
- Для экспорта CSV используется Blob и кодировка UTF-8 BOM.
