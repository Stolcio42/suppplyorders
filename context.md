# Контекст проекта "Заявки поставщикам"

## Цель
Локальное веб-приложение для формирования заявок поставщикам.
Сотрудник выбирает поставщика → добавляет товары в корзину → формирует текстовые сообщения для каждого поставщика, которые можно скопировать.

## Технологии
- HTML, CSS, JavaScript (без фреймворков)
- Запускается локально через Live Server (VS Code)
- Хранение данных: data.json для каталога товаров; localStorage для корзины и истории заказов

## Текущая структура файлов
- index.html
- style.css
- script.js
- data.json (один поставщик "Деловая упаковка" со 101 товаром)
- project-context.md (этот файл)

## Основные компоненты интерфейса
- Левая панель: список поставщиков
- Центральная панель: сетка товаров выбранного поставщика
- Правая панель (корзина): сгруппированные по поставщикам товары, управление количеством, итоговая сумма, кнопка "Сформировать сообщения", блок с готовыми сообщениями
- При узком экране (≤900px) корзина сворачивается в плавающую кнопку с бейджем количества, открывается полноэкранной панелью.
- При нажатии "Сформировать сообщения" корзина также раскрывается на весь экран (fullscreen) с разделением на зону товаров и зону сообщений (прокрутка внутри каждой).

## Особенности корзины
- Ограничение количества одного товара — 20 шт.
- Увеличение/уменьшение количества кнопками +/- и кнопка "Удалить" под каждым товаром.
- Итоговая сумма выводится над кнопкой формирования.
- Сообщения генерируются отдельно для каждого поставщика с артикулом, ценой за шт. и общим количеством.

## Что планируется добавить
- Сохранение корзины и истории заказов в localStorage (переживает перезагрузку).
- Возможность добавления нескольких поставщиков в data.json.
- При необходимости — просмотр истории заказов.

## Соглашения по data.json
- Массив объектов поставщиков: { id: number, name: string, products: [...] }
- Товар: { id: number, name: string, article?: string, unit?: string, price?: number }
